PieceOff @VERSION@ - Windows test build (x86_64 GNU)

To run:
1. Extract this folder to a location you can write to.
2. Open PowerShell in the extracted folder.
3. Run: .\pieceoff.ps1 start
4. To stop PieceOff, run: .\pieceoff.ps1 stop

This package includes the PieceOff app, the room server, and a basic FFmpeg (in
the ffmpeg folder, with its source in the source folder). It plays WebM/VP9 and
animated puzzles. For most MP4 videos (H.264/HEVC/AAC), PieceOff will offer a
one-click download of the extra codecs the first time you open one, or use
**You → Media tools → Install video codecs**.

To play with someone else, one machine runs the server (pieceoff-server.exe,
TCP port 28878) and everyone types its address into the "Room server" box.

This is an x86_64 Windows GNU build cross-compiled on Linux. It uses Windows
system DLLs and does not require a separately installed MinGW runtime. It has
not been launched on Windows by the developers yet: please report problems.
